# Mobile-Fitness-Schedule-App
A simple React Native fitness app for keeping your weekly workouts organized.

The app lets you set up workouts for each day of the week, so every day can have its own exercises, sets, and reps. You can edit exercises, add new ones, delete exercises you no longer need, and keep your routine easy to follow.

## Features

- View workouts by day of the week
- Add new exercises
- Edit exercise names, sets, and reps
- Delete exercises
- Keep each day’s workout separate and organized
- More features will be added later

## Purpose

This app is built to make workout tracking simple. Instead of writing your routine in notes or trying to remember everything, you can keep your weekly plan in one place and update it as your training changes.
